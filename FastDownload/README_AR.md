# Fast Download — Android APK

نسخة أولية قابلة للبناء إلى APK وتستهدف Android 7.0 (API 24) فأحدث.

## الوظائف الموجودة
- واجهة داكنة افتراضيًا مع حفظ اختيار الوضع الفاتح.
- لصق الرابط والتحقق الأساسي من صيغته.
- اكتشاف روابط YouTube للفيديو وقوائم التشغيل وفتحها في تطبيق YouTube.
- تقدير حجم الملفات من رؤوس HTTP إذا وفرها الخادم.
- تنزيل الملفات من روابط مباشرة مسموح بتنزيلها باستخدام Android DownloadManager.
- عرض حالة التنزيل ونسبته وحجمه عندما تتوفر البيانات.
- تنبيه أولي عند وجود تنزيل مكتمل بالاسم نفسه.

## حدود هذه النسخة
هذه النسخة لا تستخرج تدفقات YouTube ولا تنزل ملفات الفيديو أو الصوت من صفحات YouTube. كما لا تعرض عناصر القائمة كاملة ولا توفر اختيار جودة YouTube. هذه الوظائف ما زالت غير منفذة.

## بناء APK
يتم البناء تلقائيًا بواسطة GitHub Actions من ملف .github/workflows/build-fastdownload.yml، ثم رفع APK باسم FastDownload-debug-apk داخل Artifacts.
